## 코드 설명
```C
void printLine(int spaces, int stars)
{
    for (int i = 0; i < spaces; i++)
    {
        printf(" ");
    }
    for (int i = 0; i < stars; i++)
    {
        printf("*");
    }
    printf("\n");
}
```
```printLine```함수는 매개변수로 빈칸의 개수와 별의 개수를 받습니다.\n
이후 첫번째 for문에서 빈칸을 출력하여 별의 출력이 시작될 위치를 조정하고,\n
두번쨰 for문에서는 앞에서의 빈칸 출력으로 밀려난 칸에서 부터 별을 출력합니다.\n

```C
int n;

scanf("%d", &n);

if (n < 3 || n % 2 == 0)
{
    printf("3 이상의 홀수를 입력해야 합니다. \n");
    return 1;
}
```
```main```의 코드 중 일부인 위 코드는 scanf로 n이라는 변수에 입력 값을 넣고,
```if (n < 3 || n % 2 == 0)```를 통해 만약 입력이 3보다 낮거나 짝수일 경우 코드를 조기 종료 시킨 후,
3 이상의 홀수를 입력해야 함을 출력합니다.

```C
int half = n / 2;

for (int i = 0; i <= half; i++)
{
    printLine(i, n - (2 * i));
}

for (int i = half - 1; i >= 0; i--)
{
    printLine(i, n - (2 * i));
}
```
이제 이 코드에서 별을 출력하게 하는 동작을 하는 코드입니다.
예시로 3을 입력 받아 n = 3인 상황에서는 half는 1.5여야 하지만 정수 나눗셈이기 때문에 1입니다.

그러면 첫 번째 for문의 i = 0이고 1에서 멈추는 조건이 있으므로 총 0 과 1일 때 실행되기 때문에 2회 실행 됩니다,
그래서 별 3개인 줄 하나와 별이 1개이고 중앙에 있는 줄 하나가 출력됩니다.

이제 마지막 for문에서는 i = half - 1 이므로 i = 0이고 i가 0 이하일 경우 종료이므로 0일 때 실행되므로 1회 실행 됩니다,
그렇게 마지막 줄인 별 3개인 줄 하나가 출력 되며 모래시계가 출력됩니다.
